# RUNBOOK — offline / paper / testnet (P68)

## 0. Инварианты безопасности (читать до любого запуска)

- Live-режим запрещён без явного письменного разрешения пользователя.
- Стоп НЕ гарантирует максимальный убыток: гэпы, проскальзывание,
  ликвидация и отказы биржи могут увеличить потери сверх расчётного риска.
- Дневной лимит потерь зависит от определения equity (здесь:
  initial_balance + локальный realized_pnl, сброс в 00:00 UTC) и не
  эквивалентен лимиту по биржевому эквити.
- Плечо не заменяет расчёт риска: 3× плечо при риске 0.5%/сделку — это
  0.5% риска, а не 1.5%; плечо определяет маржу и дистанцию ликвидации.
- KILL-файл в корне проекта = запрет входов, выходы продолжают работать.
- `simulate=false` с валидными ключами = РЕАЛЬНЫЕ ордера (на тестнете —
  тестнет-ордера). Не вводить ключи основного счёта.

## 2. PAPER (sim, без биржи)

В config.toml для бота: `simulate = true`. Движок считает виртуальные входы/
выходы по сигнальным ценам с комиссиями (execute_simulated), позиции в state.
Ограничения paper в текущей реализации: исполнение по close сигнальной свечи
(без открытого следующего бара), без slippage-модели; результаты paper считать
верхней оценкой. Дашборд: http://localhost:9090.

## 3. TESTNET

1. `.env`: только тестнет-ключи (`FUT_TESTNET_KEY/SECRET`), RECONCILE_STRICT
   не отключать (=1). Прокси для TG — опционально (`TG_PROXY`).
2. Перед стартом: `KILL`-файл отсутствует? (присутствие = входы заблокированы).
3. Старт: `cargo build --release; .\target\release\scalping_agents.exe`.
4. Здоровье старта (в логе): TimeSync offset, фильтры загружены, reconciliation
   «сверка проведена», user-data stream запущен, супервизор активен.
5. Контроль раз в день: `💼 log_state` — флаги 🛡SL✓/TP✓ у каждой позиции;
   отсутствие «🚨 БЕЗ биржевого стопа»; отсутствие растущего счётчика
   reconcile-фантомов.
6. При банах: -1003 → входы заблокированы на 60 мин, НЕ рестартить процесс
   (каждый запрос продлевает бан).
7. Остановка: Ctrl+C — graceful shutdown (до 120с, maker для прибыльных,
   market для убыточных; sweep висячих ордеров при флэте). После стопа —
   сверка позиций на бирже.
8. Сборки: во время `cargo build` положить KILL (входы встанут на паузу).

## 4. Критерии перехода testnet → (обсуждение) ограниченного live

- ≥ 20 сделок и ≥ 8 недель на тестнете без нарушения денежных инвариантов
  (журнал trade_journal), И
- закрыты A-01 (DCA-учёт) и A-02 (risk_multiplier), И
- подтверждено поведение защитных ордеров после P69 (лог «🛡 … поставлен»
  без «🚨 БЕЗ биржевого стопа»), И
- явное разрешение пользователя + отдельный конфиг с урезанными лимитами
  (risk_per_trade_pct ≤ 0.5%, max_daily_loss_amount, PROP_MAX_DD_PCT ≤ 0.06–0.10).
Отсутствие любого пункта = остаёмся на testnet/paper.
