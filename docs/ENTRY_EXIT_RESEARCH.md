## 3. Формализованные гипотезы (протокол STRATEGY_DISCOVERY.md)

Каждая: исходная проблема → правило без заглядывания → режим рынка → издержки
→ базовый вариант → критерий опровержения.

- **H1_range_fade** (проблема: momentum-боты теряют в боковике). LONG при
  z < −2.0/−2.5 по close закрытого бара во флэте (range30 < 8%), SL 1.2ATR,
  TP 1.6ATR, вход по open следующего бара. Оповержение: OOS R ≤ 0 или
  WR ≤ be+3пп. **Результат P68: FAIL на TAO/ETH/BTC (OOS R −10…−15). Закрыта.**
- **H2_donchian_breakout** (проблема: нет трендового класса с volume-фильтром
  против ложных пробоев). Закрытие выше Donchian(20/55) + volume ≥ 1.1–1.3×avg20,
  SL 1.5ATR, TP 3ATR. **Результат P68: FAIL (OOS R −4…−11). Закрыта.**
- **H6_false_break_reversal** («ложный пробой 1 баром» из gerchik): бар
  прокалывает Donchian и закрывается обратно → вход против пробоя со стопом за
  экстремум. Зарегистрирована, НЕ тестирована в P68.
- **H3/H4/H5** — см. STRATEGY_DISCOVERY §5 (нужны данные).

## 4. Что наши тесты уже показали (наши данные, не чужие мнения)

1. Пороговые фильтры входа (TAO momentum, P66 grid, 450d): не создают edge —
   per-trade expectancy ≈ −0.16R при любых vol/atr/ofi; WR 25–29% ниже
   breakeven ~33%. Тюнинг порогов не подтверждён; остались дефолты.
2. Издержки — материалная часть минуса: cost_unit 0.13% номинала за круг ≈
   0.13–0.26R/сделку при типичных дистанциях стопа.
3. Классы mean-reversion и breakout на 1h крипто-фьючерсов в простой
   формализации убыточны после издержек; их взаимная корреляция дневных R
   отрицательная — при появлении прибыльной версии портфельный эффект
   обещает быть положительным.
