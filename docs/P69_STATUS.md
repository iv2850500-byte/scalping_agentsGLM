## Суть находки A-04
Документация Binance Futures описывает параметры защитного algo-ордера в camelCase
(algoType, triggerPrice), а код отправлял нижний регистр. Тестнет исторически
принимал нижний регистр, поэтому расхождение было латентным: при ужесточении
тестнета или переходе на прод защитный ордер мог молча не ставиться, оставляя
позицию БЕЗ биржевого стопа.

   "...поставлен через Algo API (id=...)".

   "...поставлен через Algo API camelCase (id=...)".
3. Отказ обеих форм: классический /fapi/v1/order (прежняя ветка, без изменений).
