3. КРОСС-СБОРКА EXE (Windows x64)
==============================================================================
Команда: cargo build --release --target x86_64-pc-windows-gnu
  (target уже установлен: rustup target add x86_64-pc-windows-gnu — ok)
Линкер: в песочнице нет системного mingw-w64 и нет sudo/apt, поэтому
использован автономный тулчейн llvm-mingw (clang 20.1.5 / LLVM lld,
mingw-w64 UCRT runtime): linker = x86_64-w64-mingw32-gcc.
Особенность: rustc для x86_64-pc-windows-gnu захардкожено -lgcc/-lgcc_eh;
llvm-mingw заменяет libgcc на compiler-rt + LLVM libunwind, поэтому в
проекте лежат шимы mingw_gcc_shim/:
  libgcc.a    = копия libclang_rt.builtins-x86_64.a (compiler-rt)
  libgcc_eh.a = копия libunwind.a (LLVM libunwind, SEH)
и добавлены в путь поиска (-L native=...). Профиль release дефолтный,
БЕЗ LTO (fat-LTO в P31 у пользователя не при чём — exe собирается здесь).

Результат: P33/wfa_momentum.exe
